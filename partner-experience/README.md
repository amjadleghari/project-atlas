# Partner Experience API

```
master/<vN>/openapi.yaml                  ← the master API, one folder per major version (edit here for everyone)
partners/<partner>/partner.yaml           ← partner metadata: owner, contacts, which master + overlays per version
partners/<partner>/overlays/*.yaml        ← OpenAPI Overlay 1.0 documents (edit here for one partner)
partners/<partner>/*.md(x)                ← partner documentation, published at /partners/<partner>/
generated/<partner>/<version>/openapi.*   ← GENERATED by `npm run partners` — never edit by hand
```

See the "Managing partner documentation" guide on the portal for the full workflow.
